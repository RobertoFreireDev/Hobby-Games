# Game-Boy-Color-Games-with-AI
Game Boy Color games using AI and with GBDK-2020 (C only)

## Drawing your own art

Open `tools/gbc-pixel-editor.html` in a browser: a PICO-8 style editor for the spritesheet (with palettes and tile flags), maps and objects (animations with collision boxes). It can also import images or paste them from the clipboard. Export into `resources/` (Chromium saves there directly; Firefox downloads the files for you to move), then ask the AI to use your art. Formats and the conversion to C: [docs/art-pipeline.md](docs/art-pipeline.md).
